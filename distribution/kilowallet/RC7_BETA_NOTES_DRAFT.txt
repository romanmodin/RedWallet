Physical-phone payment, channel close/resize and receipt of funds have not been verified for this publisher candidate. Do not send real funds as part of these checks.

Settings > BTC node & explorer now offers an own-node RPC connection for a Knots node on the BLAKE2b chain. Scan a synthetic RPC QR code, paste or type a connection, then inspect TEST and ADD. Multiple connections are tried in order. Plain HTTP is allowed only for local-network or onion endpoints; other endpoints require HTTPS. HTTPS requires comparing and explicitly trusting the certificate fingerprint before sending the RPC login; a changed certificate is refused. Onion connections use the built-in Tor.

With RPC enabled, the selected node supplies on-chain balance/history and receives watch-only public descriptors; it can link the wallet's addresses and activity. Recovery words and private spending keys are not part of that RPC import. The RPC login is stored in the iOS Keychain. First wallet scanning/import can take several minutes. Kilojoin and JoinBlaket still use the Electrum server. Test this only with an isolated synthetic wallet/node, not an existing production wallet or production RPC credentials.

RC7 retains JoinBlaket, existing coin controls and backups. Keep the app open for collaborative rounds; iOS only allows limited background time. A signed transaction with an unresolved broadcast remains pending and blocks conflicting work.
