## Recreate the isolated environment

Export `web/redwallet` from the exact commit into a new temporary directory;
do not install into or modify a native-app worktree. The QA-only root manifest
is:

```json
{
  "name": "redwallet-pocketic-qa",
  "private": true,
  "type": "module",
  "devDependencies": {
    "@dfinity/pic": "0.23.0",
    "@icp-sdk/core": "5.3.0",
    "ic-mops": "3.4.0",
    "vitest": "3.1.4"
  },
  "allowScripts": { "@dfinity/pic": true, "esbuild": true }
}
```

Run `npm install --no-audit --no-fund` and
`./node_modules/.bin/mops build --no-check-deploy` in that temporary directory.
Keep the saved `mops.toml` and source/test files unchanged. Save the following
as `isolated-vitest.config.mjs`:

```js
export default {
  test: {
    include: ['test/pocketic/*.test.ts'],
    environment: 'node',
    fileParallelism: false,
    maxWorkers: 1,
    minWorkers: 1,
    testTimeout: 30000,
    hookTimeout: 30000,
  },
};
```

Save this as `run-isolated-pocketic.mjs`, then run it with Node:

```js
import { PocketIcServer } from '@dfinity/pic';
import { spawn } from 'node:child_process';
import { createHash } from 'node:crypto';
import { readFile } from 'node:fs/promises';
const wasm = new URL('./src/backend/dist/backend.wasm', import.meta.url).pathname;
console.log('BACKEND_WASM_SHA256', createHash('sha256').update(await readFile(wasm)).digest('hex'));
const server = await PocketIcServer.start({ showRuntimeLogs: true, showCanisterLogs: true, ttl: 120 });
console.log('POCKET_IC_URL', server.getUrl());
try {
  process.exitCode = await new Promise(resolve => {
    const child = spawn(process.execPath, ['./node_modules/vitest/vitest.mjs', 'run', '--config', './isolated-vitest.config.mjs'], {
      cwd: new URL('.', import.meta.url).pathname,
      stdio: 'inherit',
      env: { ...process.env, POCKET_IC_URL: server.getUrl(), BACKEND_WASM: wasm },
    });
    const timer = setTimeout(() => child.kill('SIGTERM'), 120000);
    child.once('error', error => { clearTimeout(timer); console.error(error); resolve(1); });
    child.once('close', code => { clearTimeout(timer); resolve(code ?? 1); });
  });
} finally {
  await server.stop();
}
```

This explicit local QA launcher leaves the generated Caffeine sidecar runner
unchanged. It forwards the actual test exit code and does not convert an
infrastructure failure into a passing or skipped result.

## Previous timeout diagnosis

The assistant's scratch execution environment allowed the PocketIC TCP server
to start but denied its Unix-domain socket bind with `EPERM`. An independent
Unix-socket probe reproduced the same restriction. Zorin's corresponding
probe succeeded, and the suite then ran successfully there. Increasing the
timeout was not necessary.
