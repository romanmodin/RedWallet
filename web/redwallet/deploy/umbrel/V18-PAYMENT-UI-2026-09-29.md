# V18 reviewed payment workflow and device check

The full local workflow is implemented inside the CSP-gated encrypted wallet
workspace: fresh public UTXO/raw-parent preparation, immutable60-second review,
explicit acknowledgment, local XBT Unified signing, durable receipt, separate
explicit submission acknowledgment, and fresh network confirmation/archive.
Edits, lock, storage events, background/navigation and wallet changes invalidate
active reviews. Unknown results preserve exact original signed bytes and block
replacement signing. Only signed bytes/txid reach the submission API. A confirmed
receipt is archived and read back before its active slot can be cleared; a saved
state label alone can never authorize another payment.

The bridge remains ENABLE_BROADCAST=false. Preparation checks that actual
capability before funding reads, so the current release still does not send
funds. Do not describe the app as a verified complete spending wallet.

The Wallets page provides Run wallet self-test. It encrypts/decrypts a published
disposable test phrase in memory and checks exact deterministic Unified-signed
bytes against the previously node-accepted isolated-regtest fixture. It reads
no saved wallet, writes no storage, makes no network call and broadcasts nothing.
Its purpose is the remaining actual-browser/iPhone gate; a passing local test
suite does not establish an iPhone result.
